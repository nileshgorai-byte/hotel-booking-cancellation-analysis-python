# 🏨  Hotel Booking Cancellation Analysis

**Repository:** hotel-booking-cancellation-analysis-python

>  📊  Exploratory data analysis of hotel bookings to understand cancellation patterns, main drivers of cancellations, and actionable insights for hotel operations.

---

## 📂 Contents

-   `hotel_booking_cancellation_analysis.ipynb` --- Jupyter notebook
    with the complete step-by-step analysis and code.
-   `hotel_booking_report.pdf` --- Exported report summarizing findings
    and visualizations.
-   `data/` --- Folder containing the dataset(s) used for the analysis.

---

## 📌 Overview

This project investigates patterns in hotel booking cancellations. The
goal is to: 
- Explore the dataset and clean it for analysis. 
- Visualize cancellation rates across different segments. 
- Derive insights about lead time, waiting periods, and guest behavior. 
- Provide recommendations for hotel operations and potential next steps.
